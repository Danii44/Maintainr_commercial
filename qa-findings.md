# Browser QA Findings

The shared header is present on the landing page, shop, tracking page, placeholder pages, and staff access view at desktop and mobile sizes. The shop menu loads three starter UAE items with AED pricing and reference food imagery. The empty cart drawer renders correctly. Adding The Foodking Box opens the populated cart with quantity controls, AED 39.00 subtotal, AED 8.00 delivery, 5% VAT, and AED 48.95 total. The COD form displays name, mobile, delivery address, optional notes, and the calculated amount. A QA checkout created tracking code FK-MT4S5E6R, and /track successfully rendered the received status, delivery address, amount, payment method, and event timeline. Invalid tracking code INVALID rendered the expected error message. The remaining check is explicit inline checkout validation after the shared-header refactor.
After the final refactor, submitting the empty COD form rendered the explicit inline alert: “Please complete your name, mobile number, and delivery address.” This confirms the custom validation state is visible and accessible in the current live preview.
